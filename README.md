# 워리어스: 레전드 오브 트로이 (PS3, BLES01183) 비공식 한글패치

코에이 테크모의 PS3 게임 **Warriors: Legends of Troy**(트로이 무쌍) 유럽판에 적용하는 비공식 한글패치입니다.

- 제작: **용가리 (Yonggary6425)**
- 최신 버전: **v1.0.2** (2026-10-25)

이 저장소에는 패치 제작 도구와 기술 문서만 들어 있습니다. 게임 원본 데이터, 영어 원문, 번역 대본은 포함하지 않습니다.
패치 파일은 [Releases](../../releases)에서 받으세요.

## 받는 파일

[Releases](../../releases)에서 상황에 맞는 파일 하나를 받으세요.

| 파일 | 이런 분께 | 설명 |
|---|---|---|
| `Troy_KOR_Patch_v1.0.2_full.zip` | **처음 적용하는 분** (원본 ISO·폴더), v1.0·v1.0.1 사용자도 가능 | 전체 패치. 원본이든 이전 버전 적용본이든 v1.0.2로 만듭니다. 폴더 백업·원본 되돌리기 지원 |

## 원본

| 항목 | 값 |
|---|---|
| 게임 ID | BLES01183 (유럽판, 디스크 버전 01.00) |
| 파일 형식 | 복호화(decrypted)된 ISO, 또는 ISO를 압축 해제한 게임 폴더 |
| 파일명 (예시) | `Warriors Legends of Troy [E].iso` |
| 크기 | 14,682,554,368 바이트 |
| MD5 | `e1be3b6f22d9f5783e2e98ad3008019e` |

> 위 MD5는 제작에 쓴 ISO의 값입니다. 덤프 도구에 따라 ISO 전체 해시가 다를 수 있는데, 이 경우에도 패처가 바꿀 원본 파일 103개의 SHA-1을 하나씩 확인하므로 패처가 거부하지 않으면 그대로 쓰셔도 됩니다.

> 북미판(BLUS) 등 다른 판본이나 암호화된 ISO에는 적용되지 않습니다. 패처가 적용 전에 자동으로 확인한 뒤 거부합니다.

## 적용 방법

패처(`TroyKOR_Patcher.exe` 또는 업데이트용 `TroyKOR_Patcher_Update.exe`) 위에 **게임 폴더** 또는 **ISO 파일**을 끌어다 놓습니다. (또는 실행한 뒤 창에 끌어다 놓고 Enter)

### 게임 폴더에 적용 (RPCS3 권장)

1. `PS3_GAME` 폴더가 들어 있는 폴더(또는 `PS3_GAME` 폴더 자체)를 끌어다 놓습니다.
2. 바뀌는 원본 파일은 게임 폴더 안 `TroyKOR_backup` 폴더에 백업한 뒤 적용합니다.
3. `완료!`가 나오면 끝입니다. 이미 패치된 폴더를 전체 패처에 다시 넣으면 원본으로 되돌릴 수 있습니다.

### ISO 파일에 적용

1. 원본 ISO를 끌어다 놓습니다.
2. 저장 방식을 고릅니다.
   - `[1]` 새 ISO로 저장 (권장): 원본은 그대로 두고 `… [KOR].iso`를 새로 만듭니다.
   - `[2]` 원본 ISO에 바로 적용: 빠르지만 원본이 바뀝니다.
3. `완료!`가 나오면 끝입니다.

ISO에 적용할 때는 ISO9660·Joliet 파일 목록과 함께 **UDF 파일 목록**도 고칩니다(v1.0.2부터). 그래서 패치한 ISO를 반디집·WinRAR·7-Zip 등 어떤 프로그램으로 풀어도 한글판 파일이 나옵니다.

패처는 적용 전에 게임 ID와 바꿀 원본 파일 103개의 SHA-1을 확인하고, 적용 후 결과 파일을 다시 읽어 검증합니다. 이미 패치된 ISO나 폴더에 다시 실행해도 안전합니다.

### 한글 대신 빈칸이 보일 때

문장 속 영문과 기호만 보이고 한글이 비어 있다면, 글꼴 파일(`fonts.g1n`)이 원본인 상태입니다.

**원인**: PS3 게임 ISO에는 파일 목록이 세 벌(ISO9660, Joliet, UDF) 들어 있습니다. v1.0·v1.0.1 패처는 앞의 두 목록만 고쳤습니다.
- RPCS3에서 ISO를 직접 실행하면 문제가 없습니다.
- 반디집·WinRAR처럼 UDF 목록을 읽는 프로그램으로 풀면, 크기가 커져 ISO 끝으로 옮긴 파일(글꼴 등)은 원본이 나옵니다.
- 제자리에 덮어쓴 파일(텍스트)은 한글판 뒤에 원본 찌꺼기가 붙어 나옵니다.

그 결과 한국어 텍스트를 원본 글꼴로 그리게 되어 한글이 빈칸으로 보입니다.

**해결**: v1.0.2 **전체 패처**에 다음 중 하나를 끌어다 놓으세요.
- 그 ISO: 빠진 파일을 적용하고 UDF 목록까지 고칩니다.
- 이미 풀어 둔 게임 폴더: 원본으로 남은 파일은 적용하고, 뒤에 찌꺼기가 붙은 파일은 잘라 바로잡습니다.

### 실행 시 설정

- RPCS3 / PS3의 **시스템 언어를 English**로 설정하세요. 영어 데이터 자리에 한국어를 넣는 방식입니다.
- 게임 옵션에서 HDD 설치(INSTALL)를 이미 했다면, 설치 데이터를 지우고 다시 설치하세요.

## 한글화 범위

### 텍스트
- 3,395줄 (서로 다른 문장 2,534개)
  - 메뉴·도움말·아이템·로딩 팁 1,727줄
  - 인게임 대사 793줄
  - 컷신 자막 629줄
  - 목표·튜토리얼 246줄
- 인명·지명은 그리스어 원음 표기를 따랐습니다. 예: 아이아스, 헥토르, 헬레네, 트로이아, 아카이아인
- 인물 관계에 따라 하게체, 하오체, 해라체를 나눠 고대 서사시 분위기를 살렸습니다.

### 글꼴
- 게임 비트맵 글꼴(`fonts.g1n`) 4종에 한글 825자를 추가했습니다.
- 자막·안내문에 쓰이는 0번 글꼴의 한글은 읽기 쉽도록 영문 대문자보다 크게(20px) 그렸습니다. (v1.0.2)
- 원본의 외곽선, 그림자, 입체 음영을 분석해 한글에도 같은 방식으로 적용했습니다.

### 이미지
- 챕터·도전 모드 제목 27장
- 메인 메뉴(선택/기본 상태), 인물 이름표 8명
- 화면 제목: 장 선택, 도전, 캐릭터 선택, 부록, 일시정지 메뉴, 결과 화면, 패배, 옵션
- 타이틀 화면 안내 문구, 난이도 표시 4종, HUD의 「클레오스」

### 그대로 둔 항목
- 타이틀 로고, 저작권 표기
- 음성
- 갤러리 원화
