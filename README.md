# 워리어스: 레전드 오브 트로이 (PS3, BLES01183) 비공식 한글패치

코에이 테크모의 PS3 게임 **Warriors: Legends of Troy**(트로이 무쌍) 유럽판에 적용하는 비공식 한글패치입니다.

- 제작: **용가리 (Yonggary6425)**
- 최신 버전: **v1.0** (2026-10-23)

이 저장소에는 패치 제작 도구와 기술 문서만 들어 있습니다. 게임 원본 데이터, 영어 원문, 번역 대본은 포함하지 않습니다.
패치 파일은 [Releases](../../releases)에서 받으세요.

## 받는 파일

| 파일 | 설명 |
|---|---|
| `Troy_KOR_Patch_v1.0.zip` | Windows용 ISO 패처(`TroyKOR_Patcher.exe`)와 설명서 |

### 파일 해시

| 파일 | MD5 | SHA-256 |
|---|---|---|
| `Troy_KOR_Patch_v1.0.zip` | `90684c9babfa233878111e7e2348b969` | `b83a02ed1f5702152fbb2dd12b3871996d049c8aae2f366e98cee852d766482d` |
| `TroyKOR_Patcher.exe` | `f6723c6e6ae95084e9e6c5f7a11c53f9` | `362c7093fcf1a4abf0f4a9f20614622ff300d582570c99a1db8047ba9f22921e` |

받은 파일이 맞는지 확인하려면 PowerShell에서 다음을 실행해 위 값과 비교하세요.

```powershell
Get-FileHash .\Troy_KOR_Patch_v1.0.zip -Algorithm MD5
Get-FileHash .\Troy_KOR_Patch_v1.0.zip -Algorithm SHA256
```

패처 안에는 바뀐 부분(차분)만 들어 있으며, 나머지는 사용자의 원본 ISO에서 읽어 조립합니다.

## 원본

| 항목 | 값 |
|---|---|
| 게임 ID | BLES01183 (유럽판, 디스크 버전 01.03) |
| 파일 형식 | 복호화(decrypted)된 ISO |
| 파일명 (예시) | `Warriors Legends of Troy [E].iso` |
| 크기 | 14,682,554,368 바이트 |
| MD5 | `e1be3b6f22d9f5783e2e98ad3008019e` |

> 위 MD5는 제작에 쓴 ISO의 값입니다. 덤프 도구에 따라 ISO 전체 해시가 다를 수 있는데, 이 경우에도 패처가 바꿀 원본 파일 103개의 SHA-1을 하나씩 확인하므로 패처가 거부하지 않으면 그대로 쓰셔도 됩니다.

> 북미판(BLUS) 등 다른 판본이나 암호화된 ISO에는 적용되지 않습니다. 패처가 적용 전에 자동으로 확인한 뒤 거부합니다.

## 적용 방법

1. `TroyKOR_Patcher.exe` 위에 원본 ISO를 끌어다 놓습니다.
   (또는 실행한 뒤 창에 ISO를 끌어다 놓고 Enter)
2. 저장 방식을 고릅니다.
   - `[1]` 새 ISO로 저장 (권장): 원본은 그대로 두고 `… [KOR].iso`를 새로 만듭니다.
   - `[2]` 원본 ISO에 바로 적용: 빠르지만 원본이 바뀝니다.
3. `완료!`가 나오면 끝입니다.

패처는 적용 전에 게임 ID와 바꿀 원본 파일 103개의 SHA-1을 확인합니다. 적용 후에는 ISO 디렉터리를 다시 읽어 결과 파일을 검증합니다. 이미 패치된 ISO에 다시 실행해도 안전합니다.

### 실행 시 설정

- RPCS3 / PS3의 **시스템 언어를 English**로 설정하세요. 영어 데이터 자리에 한국어를 넣는 방식입니다.
- 게임 옵션에서 HDD 설치(INSTALL)를 이미 했다면, 설치 데이터를 지우고 다시 설치하세요.

## 한글화 범위

### 텍스트
- 3,395줄 (서로 다른 문장 2,534개)
  - 메뉴·도움말·아이템·로딩 팁 1,727줄
  - 인게임 대사 793줄
  - 컷신 자막 629줄
  - 목표·튜토리얼 246줄
- 인명·지명은 그리스어 원음 표기를 따랐습니다. 예: 아이아스, 헥토르, 헬레네, 트로이아, 아카이아인
- 인물 관계에 따라 하게체, 하오체, 해라체를 나눠 고대 서사시 분위기를 살렸습니다.

### 글꼴
- 게임 비트맵 글꼴(`fonts.g1n`) 4종에 한글 825자를 추가했습니다.
- 원본의 외곽선, 그림자, 입체 음영을 분석해 한글에도 같은 방식으로 적용했습니다.

### 이미지
- 챕터·도전 모드 제목 27장
- 메인 메뉴(선택/기본 상태), 인물 이름표 8명
- 화면 제목: 장 선택, 도전, 캐릭터 선택, 부록, 일시정지 메뉴, 결과 화면, 패배, 옵션
- 타이틀 화면 안내 문구, 난이도 표시 4종, HUD의 「클레오스」

### 그대로 둔 항목
- 타이틀 로고, 저작권 표기
- 음성
- 갤러리 원화
