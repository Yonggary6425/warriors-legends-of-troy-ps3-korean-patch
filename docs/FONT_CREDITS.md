# 글꼴 출처

한글 글리프는 다음 글꼴로 그린 뒤, 게임 비트맵 글꼴(`fonts.g1n`) 형식으로 바꿔 넣었습니다.
텍스처의 한글 글자(장 제목, 메뉴, 이름표 등)도 같은 글꼴로 그렸습니다.

| 글꼴 | 저작권 | 사용한 곳 |
|---|---|---|
| IBM Plex Sans KR SemiBold | Copyright © 2017 IBM Corp. | 0번 글꼴 (자막, 안내문) |
| Gowun Dodum (고운돋움) | Copyright 2021 The Gowun Project Authors | 1번·2번 글꼴 (본문) |
| Noto Serif KR (본명조) Black | Copyright 2017–2021 Google LLC / Adobe | 3번 글꼴 (장식체), 이미지 글자 |

세 글꼴 모두 **SIL Open Font License 1.1**로 배포됩니다.

- 라이선스 전문: https://openfontlicense.org/open-font-license-official-text/
- 받은 곳: https://github.com/google/fonts (`ofl/ibmplexsanskr`, `ofl/gowundodum`, `ofl/notoserifkr`)

OFL에 따라 위 글꼴은 자유롭게 사용, 수정, 재배포할 수 있습니다.
이 패치는 글꼴 파일 자체를 배포하지 않습니다. 게임 내 비트맵으로 바꾼 결과만 들어 있으며, 원 글꼴의 저작권 표기를 여기에 남깁니다.
